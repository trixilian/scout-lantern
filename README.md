# Scout Lantern

A card search & filter web UI for Kingdom Death: Monster gear cards. Built with
**SvelteKit** (Svelte + TypeScript) as a static site (`adapter-static`) and hosted on
**GitHub Pages**.

The page downloads all card data once (`data/cards.json`) and searches it in the browser
with [MiniSearch](https://github.com/lucaong/minisearch). There is no backend.

## Card data

All cards live in `static/data/cards.json`. The file is generated by a separate export tool
and committed here as is, so don't edit it by hand: re-run the export, then commit the
updated file. Its shape is described by the types in `src/lib/types.ts`; the `version`
field must match `DATA_VERSION` there.

Unit tests use the small fixture in `src/lib/fixtures/cards.json` instead, so they don't
change whenever the card data does.

## Develop

```bash
npm install
npm run dev
```

Then open <http://localhost:5173>.

Checks (also run by CI on every push):

```bash
npm run lint
npm run check
npm test
```

## Deploy

```bash
npm run deploy
```

`scripts/deploy.sh` builds the site with the `/scout-lantern` base path and force-pushes the
contents of `build/` as a single commit to the `gh-pages` branch. It deploys the working
tree, so commit first (including any updated `static/data/cards.json`).
The site is then served at <https://trixilian.github.io/scout-lantern/>.

One-time setup: in the GitHub repo settings under **Pages**, set the source to
"Deploy from a branch", branch `gh-pages`, folder `/ (root)`.

`static/.nojekyll` stops GitHub Pages from running Jekyll, which would otherwise drop the
`_app/` folder.

To preview a production build locally:

```bash
npm run build
npm run preview
```
